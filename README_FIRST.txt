ABHAY CHOUHAN PORTFOLIO — QUICK START
======================================

This folder contains the complete portfolio source code and assets.

WINDOWS
1. Double-click start.bat
2. Open http://localhost:4173

MACOS / LINUX
1. Open Terminal in this folder
2. Run: chmod +x start.sh
3. Run: ./start.sh
4. Open http://localhost:4173

MANUAL START
Run: python3 server.py
Then open: http://localhost:4173

No npm install is required.
Read README.md for complete setup, customization, deployment, résumé,
and contact-form activation instructions.
